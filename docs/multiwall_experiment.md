# Шаг 8. Маршрут через две стены

Опыт с координатами показал, что локальная стратегия может быть лучше
глобальной карты. Теперь `agent x/y` всегда равны нулю, а агенту нужно пройти
не одну, а две двери подряд.

## Вопрос опыта

Сможет ли мозг повторно применить правило обхода препятствия и изменить
направление, если вторая дверь находится с другой стороны?

## Два типа маршрута

Две параллельные стены делят поле на три части:

```text
same side   обе двери находятся с одной стороны
zigzag      вторая дверь находится с противоположной стороны
```

`same side` можно решить продолжением одного бокового движения. `zigzag`
требует после первой стены перестроить маршрут.

Один сбалансированный блок содержит 16 категорий:

```text
2 ориентации * 2 стороны старта * 2 стороны первой двери * 2 маршрута
```

## Что видит мозг

Он получает направление и расстояние до еды, bias и три wall-сенсора.
Позиционные входы существуют, но всегда равны нулю. Координаты дверей и номер
пройденной стены не передаются.

Fitness использует длину доступного маршрута через еще не пройденные двери.
Это плавная оценка для эволюции, а не дополнительный сенсор мозга.

## 1. Короткая демонстрация

```powershell
uv run python -m experiments.generalize_multiwall --generations 10 --population 24 --episodes 16 --validation-episodes 16 --holdout-episodes 16 --max-steps 160 --workers 4 --open-viewer
```

Найди в viewer `same side` и `zigzag`. Проследи, пересекает ли агент первую
стену, меняет ли боковое направление и пересекает ли вторую. Десять поколений
могут показать только начало обучения.

## 2. Полный запуск

```powershell
uv run python -m experiments.generalize_multiwall --generations 50 --population 80 --episodes 32 --validation-episodes 32 --holdout-episodes 64 --max-steps 160 --workers 4 --open-viewer
```

Training, validation и holdout используют разные сцены. Validation выбирает
checkpoint, после чего holdout один раз проверяет новые маршруты.

## Как читать отчет

Проверяй метрики в таком порядке:

1. `Crossed both`: пройдены ли обе стены.
2. `Eat rate`: завершен ли весь путь до еды.
3. `Same side / Zigzag`: умеет ли мозг перестраивать направление.
4. `Vertical / Horizontal`: переносится ли правило при повороте мира.
5. `Stuck` и collisions: не достигнут ли успех грубым трением о стену.

Высокий `Crossed both` и более низкий `Eat rate` означает, что основная
навигация найдена, но после второй стены агент не всегда успевает к цели.
Низкий `Crossed both` указывает на проблему именно с последовательностью
дверей.

Ориентиры одиночного запуска:

```text
holdout eat rate >= 70%
crossed both     >= 80%
stuck            <= 15%
same/zigzag gap  <= 20 п.п.
```

## Наш одиночный результат

```text
validation = 100%
holdout = 96.88%
crossed both = 96.88%
stuck = 1.56%
generalization gap = +3.12 п.п.
```

Маленький gap и высокий результат обеих категорий показали, что локальная
стратегия перенеслась на длинный маршрут.
