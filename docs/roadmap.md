# Дорога от маленькой сети к модели мухи

Этот файл является картой исследования и журналом фактических результатов.
Подробные объяснения и короткие команды находятся в связанных главах.

Обозначения:

- `[x]` эксперимент реализован и проверен;
- `[ ]` следующий вывод еще нельзя считать подтвержденным;
- PASS относится только к указанному протоколу, а не ко всем возможным мирам.

## Шаг 0. Научиться наблюдать систему

- [x] Запуск через `uv` и автоматические тесты.
- [x] Live viewer во время эволюции.
- [x] Самостоятельный `viewer.html` после завершения.
- [x] Несколько процессов оценивают кандидатов внутри поколения.

Начать отсюда: [как работает система](how_it_works.md).

Главный урок: сначала нужно видеть сенсоры, действия и метрики, иначе красивое
движение легко принять за способность, которой у мозга нет.

## Шаг 1. Реактивная навигация

- [x] Маленький recurrent-мозг получает сенсоры еды.
- [x] Эволюция меняет веса и число hidden-нейронов.
- [x] Агент учится приближаться и касаться видимой цели.

Это базовая проверка всего контура `мир -> мозг -> действие -> fitness`.

## Шаг 2. Память о скрытой цели

### Абсолютные координаты

- [x] Retraining без `agent x/y`: эффект `-10.94` п.п.
- [x] Knockout готовых full-мозгов: падение `18.75` п.п.

## Шаг 6. Память правила A/B

- [x] Две цели остаются видимыми, команда исчезает до начала движения.
- [x] Recurrent, stateless и test-time knockout используют один протокол.
- [x] Первый одиночный результат: `92.19%` против `46.88%`, knockout `42.19%`.
- [x] Первый пятиseed-тест обнаружил нестабильность: recurrent mean `59.69%`,
  stateless `50.00%`, только `1/5` recurrent выше `70%`. Итог: FAIL.

FAIL здесь был полезнее еще одного красивого replay. Он показал, что мозг мог
использовать память, но эволюция часто находила угловые специализации.

### Исправление протокола

- [x] Cue представлен симметрично: `A = +1`, `B = -1`.
- [x] Каждая геометрия имеет точную пару с противоположной командой.
- [x] Pair alignment дает плавный сигнал, когда cue уже меняет направление, но
  агент еще не дошел до цели.
- [x] Pair contrast отмечает пары, где агент уже завершил два разных выбора.
- [x] Fitness и checkpoint защищают худшую из восьми категорий.
- [x] Добавлен плавный score худшей категории.
- [x] Между поколениями вращаются 16 training-банков.
- [x] Validation увеличен до 64 сбалансированных сцен.
- [x] Контрольный seed `7`: recurrent `100%`, stateless `50%`, knockout `50%`,
  худшая recurrent-категория `100%`.
- [x] Проблемный seed `27`: при 40 поколениях holdout `59.38%`, при 60
  поколениях validation и holdout `100%`; alignment вырос до успеха.
- [x] Новый пятиseed-протокол пройден без ослабления критериев: recurrent
  `94.06%`, stateless `50.00%`, преимущество `44.06` п.п., knockout drop
  `62.81` п.п., `5/5` recurrent-запусков выше `70%`.
- [x] Худшая объединенная recurrent-категория получила `90%`. Итог: PASS.

Лабораторные работы:

- [устройство выбора цели](target_choice_experiment.md);
- [пятиseed-сравнение](target_choice_comparison.md).

Остаточное наблюдение: seed `37` получил `81.25%` holdout, но две его отдельные
категории остановились на `50%`. Групповой протокол пройден, однако одна
эволюция все еще может найти неполное правило.

## Шаг 7. Переход к Drosophila

После PASS предыдущего протокола начинаем новый уровень, не смешивая его с
отладкой маленькой сети:

1. Изучить формат нейронов и связей FlyWire/Codex.
2. Выбрать небольшой известный сенсомоторный контур, а не весь connectome.
3. Запустить готовую LIF-модель без нашей среды и проверить ее динамику.
4. Сделать адаптер из сенсоров мира в spike-входы и из моторных нейронов в
   действия.
5. Сначала повторить простой `find_food`, затем память и препятствия.
6. Сравнивать connectome-модель с маленькой сетью на одинаковых сценах.

Мы переходим к мухе не потому, что маленькая модель стала биологичной. Она
дала нам измерительный стенд: контроль, holdout, ablation, повторяемость и
viewer, с которыми можно не потеряться в гораздо более сложной системе.
