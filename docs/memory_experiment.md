# Шаг 2. Память о скрытой цели

В `find_food` агент все время видит еду. Поэтому успех еще не доказывает
память: достаточно непрерывно реагировать на текущий сигнал. Здесь мы на
несколько шагов показываем цель, затем выключаем сигнал и только после этого
разрешаем движение.

## Вопрос опыта

Может ли рекуррентный мозг сохранить направление на цель во внутреннем
состоянии и использовать его, когда сенсор уже молчит?

## Как проходит один эпизод

```text
cue phase       еда видна, агент неподвижен
hidden phase    сенсоры еды равны нулю, агент движется
success         агент касается физической цели
```

В viewer пунктирная еда после cue phase видна нам, но не агенту. Это важное
различие: визуализация показывает истинное состояние мира, а полосы `Sensors`
показывают информацию мозга.

## 1. Коротко познакомься с задачей

```powershell
uv run python -m experiments.remember_food --generations 8 --population 24 --episodes 4 --max-steps 60 --visible-steps 6 --workers 4 --open-viewer
```

Проверь глазами:

1. Пока цель заполнена цветом, тело не меняет положение.
2. Когда цель становится пунктирной, первые три сенсора становятся нулевыми.
3. В hidden phase тело начинает двигаться.
4. Цвета hidden-нейронов продолжают изменяться без сигнала цели.

Короткий запуск предназначен для понимания интерфейса. Он может не успеть
найти хорошую стратегию.

## 2. Обучи recurrent-мозг

```powershell
uv run python -m experiments.remember_food --generations 30 --population 60 --episodes 10 --max-steps 60 --visible-steps 6 --workers 4 --open-viewer
```

`--visible-steps 6` означает шесть неподвижных шагов с видимой целью. На этих
шагах recurrent-связи могут записать ориентир в hidden-state.

## 3. Запусти контроль без памяти

```powershell
uv run python -m experiments.remember_food --generations 30 --population 60 --episodes 10 --max-steps 60 --visible-steps 6 --workers 4 --no-recurrence --open-viewer
```

Флаг `--no-recurrence` не удаляет hidden-нейроны. Перед каждым шагом он
сбрасывает их прошлое состояние. Сеть по-прежнему может реагировать на текущие
сенсоры, но не может перенести информацию из cue phase в hidden phase.

Это хороший контроль, потому что все остальное остается тем же: мир, число
нейронов, моторы, fitness и длительность эпизода.

## 4. Проведи парное сравнение

```powershell
uv run python -m experiments.compare_memory --generations 30 --population 60 --episodes 10 --max-steps 60 --visible-steps 6 --holdout-episodes 30 --workers 4 --replicates 3 --open-viewer
```

Для каждого повтора команда отдельно обучает recurrent и stateless условия.
Внутри пары они получают сопоставимые сцены, после чего проходят новые
holdout-эпизоды. Один viewer последовательно показывает текущие условие и
повтор, а в конце оставляет четыре лучших запуска.

## Что считать свидетельством памяти

Смотри прежде всего на `Holdout eat rate`:

```text
recurrent заметно выше stateless
разница повторяется на нескольких seed
успех остается на новых holdout-сценах
```

Stateless может иногда попасть в цель случайно или лететь по удачной
фиксированной траектории. Поэтому доказательством является не его абсолютный
ноль, а воспроизводимое преимущество recurrent.

## Как читать результаты

В `results/compare_memory/<run-id>/`:

- `report.md` содержит средние результаты двух условий;
- `comparison.csv` содержит отдельную строку каждого повтора;
- `comparison-viewer.html` показывает лучших победителей вместе;
- `visualizations/*/viewer.html` содержит весь holdout конкретного запуска;
- `*-best_genome.json` хранит веса победителей.

Сначала сравни таблицы. Затем в viewer включи фильтр `Failure` и спроси:

- агент правильно поворачивает, но не успевает дойти;
- сразу выбирает постоянное направление;
- начинает верно, а затем теряет курс;
- hidden-state после исчезновения цели остается различимым или быстро затухает.

Последний пункт является наблюдением, а не доказательством роли отдельного
нейрона. Причинную роль проверяют выключением связи или состояния.

усложняет не память, а геометрию: [перенос навигации в комнаты со стеной](generalization_experiment.md).
